# 0014 Name: `site-to-api`

Status: Accepted (2026-10-28)

## Context
Comparable tools use plain, searchable names (reverse-api-engineer, mitmproxy2swagger,
derive-client). Clever names (`dowse`, `apisonde`) collided with existing projects and are not
what people search for.

## Decision
`site-to-api`: free on npm, no notable GitHub project with that name, describes the outcome.
Rejected: `api-discovery` (an established term for security inventory products), `har2api` (names
the input format), `api-reverse` (reads as a copy of reverse-api-engineer).

## Consequences
Trademark clearance has not been done; run the `oss-launch` name-clearance step before the public
release.
