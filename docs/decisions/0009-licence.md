# 0009 MIT licence, DCO sign-off

Status: Accepted (2026-10-28)

## Context
Goal: widest adoption by individual developers and companies; no business model. Dependencies are
MIT/Apache-2.0/BSD/ISC, all compatible with a permissive licence. The code is written by the
maintainer on personal time.

## Decision
MIT ("maximum adoption" posture). Contributions under the Developer Certificate of Origin via
`Signed-off-by` trailers; no CLA.

## Consequences
No explicit patent grant (Apache-2.0 would add one). Revisit if corporate contributors or a
foundation enter the picture. The maintainer should confirm no employment agreement claims the
code before publishing.
