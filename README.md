# site-to-api

Capture a website's traffic once and get everything a coding agent needs to build a wrapper for
it: OpenAPI 3.1 specs, request flows with their dependencies, pointers into the site's own source
code, and a typed client with Zod validation.

> Status: under active development, not yet published.
